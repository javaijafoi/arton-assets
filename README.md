# arton-assets

Retratos de personagens carregados pela [Arena de Arton](https://arena-de-arton.vercel.app), uma homenagem de fã, gratuita e sem fins lucrativos.

As ilustrações são da **Jambô Editora** (revista/material de *Tormenta20*), usadas apenas como homenagem. Este repositório é separado do código do jogo de propósito e **será removido a pedido da Jambô**. Se as imagens saírem do ar, o jogo volta sozinho aos emblemas genéricos.

Todos os direitos sobre as imagens pertencem aos seus autores e à Jambô Editora.
